Durante este proyecto se realizó el diseño de un soporte para teléfono utilizando Autodesk Fusion 360. Primero se observaron diferentes modelos de soportes para tener una idea de cómo podía ser el diseño y qué partes se necesitaban.

Primero se hizo la base del soporte utilizando un Sketch. Se dibujó un rectángulo y se agregaron las medidas necesarias para que tuviera un tamaño adecuado y pudiera mantener estable el teléfono. Después se utilizó la herramienta Extrude para darle grosor y convertir la base en una pieza 3D.

Luego se realizó la parte inclinada donde se coloca el teléfono. Para esto se hizo otro Sketch con la forma de la pieza y después se utilizó Extrude para darle volumen. También se acomodó la pieza hasta conseguir un ángulo adecuado para colocar el teléfono.

Después se fueron agregando las demás partes del soporte. Se utilizaron diferentes Sketches, extrusiones y la herramienta Move/Copy para formar las piezas y colocarlas en la posición correcta. Durante este proceso se revisaron las medidas y la posición de las piezas para que quedaran bien alineadas.

Una de las partes que más trabajo requirió fueron los ganchos delanteros, que sirven para sostener el teléfono y evitar que se deslice. Primero se realizó un Sketch con la forma del gancho y luego se utilizó Extrude para darle volumen. Después se copió el cuerpo y se utilizó Move/Copy para colocar el segundo gancho en el lado contrario.

Durante el proceso se utilizaron herramientas como Sketch, Line, Rectangle, Extrude, Move/Copy y Fillet. Algunas partes tuvieron que ajustarse varias veces para conseguir que las piezas quedaran correctamente conectadas y alineadas.

Al finalizar, se obtuvo un modelo 3D completo de un soporte para teléfono. El diseño cuenta con una base, una parte inclinada para colocar el celular y dos ganchos delanteros para sostenerlo. Con este proceso se logró conocer mejor el funcionamiento de Fusion 360 y la forma de crear un objeto tridimensional a partir de dibujos y medidas.
